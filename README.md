# BizzSoft con logo

Esta versión incluye el logo enviado por el usuario y mantiene el buscador funcionando con Django.

## Ejecutar en Windows

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Abre:

http://127.0.0.1:8000/

No uses Live Server para este proyecto.
